# 客户要看样例

先发真实案例；没有对口案例（或当前环境未挂载 `assets/cases/` 及共享案例目录）时，直接发包内 `assets/sample-screenshots/` 的公开数据库存图；库存里也没有的方法，有 Mac 权限时用公开数据现场跑一张，无 Mac 权限时发最接近的库存图并提醒 Daly 或客服主管补截。

## 发什么、发几张

- 挑和客户方法最接近的一组，一次两三张，每次只回问到的那一点。
- 客户第一句同时点名要 do 和结果：结果表上下两张加 do，三张一起发。
- 只说要看结果：先发结果表上下两张；客户怀疑不是真跑，再发 do；问还能做哪些，再发检验表。
- 客户是 DID：先发最接近的真实案例；点名要看 DID，再发库存里的多期 DID 图。

## 发图时的对客话

- 发图不配解说，客户追问图里的细节时再解释，问到哪说哪。
- 客户问「有没有」，先直接答一句再发图；回答问题不算解说。
- 发完图要转话题，问句带一个跟上一句相关的理由，不凭空换话题。
- 理由落在客户自己的事上，不落在案例上；不说案例不对口、不全这类话。
- 客户发了文件不必说收到了，有问题直接回答，没问题就带到下一步（通则）。

## 案例以外的东西不给

客户要原文件、数据、论文、没裁过的图或别的成品：以保护客户隐私为由不给，顺带说他的也一样不会给别人看。

## 做新案例

- 只用 Daly 发来的成品，Stata 真截，不用程序生成图。
- 个人信息（论文标题/题目、学校、姓名、学号、微信、平台、价格、用户名路径）靠裁剪去掉，不打码；数据、变量名、系数保留。截图用的副本可以去掉论文题目和多余备注，不改数字。
- 发前查：备注和标准误类型一致、代码和表对得上、没有 0.0000、没有残行残图标、窗口是激活状态。

## 现场截图（客户要看库存里没有的方法，比如 PSM、面板固定效应）

客户不用给数据，我用 Stata 自带或公开数据（`sysuse`/`webuse`）按同类方法跑一张；不用任何客户的 do、数据、结果，也不拿新客户发来的数据试跑截图。

1. 先回客户一句稍等，说马上跑一张给他看。
2. 在 Daly 的 Mac（machineId `08e6a1a6-2df7-46c9-9c7a-607fdeeb82aa`）的 `~/Documents/样例截图/` 写一份新 do（照 `baseline.do` 的结构：中文注释、逐步加控制、esttab 出表）。
3. 先后台静默跑一遍查显著：`<Stata 安装目录>/StataMP.app/Contents/MacOS/stata-mp -b do 新文件.do`，看 `新文件.log` 里核心变量是否显著。不显著就不截，换变量或换公开数据重跑；实在不行改发库存图。显著了再删掉 log。
4. 用 osascript 让 Stata 运行：`tell application "StataMP" to DoCommand "cd ~/Documents/样例截图"`，再 `DoCommand "cls"`、`DoCommand "doedit 新文件.do"`、`DoCommand "do 新文件.do"`。
5. 用 System Events 调窗口位置和大小，并 AXRaise 到最前；用 CGWindowListCopyWindowInfo 查 Stata 窗口号，再 `screencapture -x -o -l<窗口号>` 截单个窗口。查窗口号的 swift：
   `import CoreGraphics; let l = CGWindowListCopyWindowInfo([.optionOnScreenOnly], kCGNullWindowID) as! [[String:Any]]; for w in l { if let o = w["kCGWindowOwnerName"] as? String, o.contains("Stata") { print(w["kCGWindowNumber"]!, w["kCGWindowName"] ?? "") } }`
6. 拷回 box 后裁剪，发出前逐项检查：底部路径栏（含用户名）已裁掉；标题栏、编辑器标签页没有客户文件名；表格从表头到 end of do-file 完整；没有平台、价格、客户信息。
7. 发一两张，好用的存进 `assets/sample-screenshots/` 并更新这里的清单。

没有 Mac 访问权限的岗位：只发库存图，并提醒 Daly 或客服主管现场补截。

## 客户疑问怎么回（原则，现想现说）

每次只回客户问到的那一点，不把下面几条一次讲完。

- 认出是教材示例数据，或觉得只是演示：大方承认是公开数据，改发对口的真实案例截图。
- 要看别人做好的成品或原文件：先发真实案例截图；案例以外的不给，见上文。
- 怀疑不是真跑的：指出截图是 Stata 窗口里实际运行到 end of do-file 的；交付时给完整 do 和数据，能自己复现。
- 看出 DID 库存图不是中国数据：照实说是公开数据，多期 DID 的做法和国别无关；要看真实案例就发最接近的真实案例，不说成中国数据。
- 问样例方法和自己不同：说做法通用，愿意的话我用公开数据按同类方法跑一张，他不用给数据。
